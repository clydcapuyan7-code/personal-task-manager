# Personal Task Manager

A simple and efficient task management web application built with **Laravel** to help you organize your daily tasks, track progress, and stay productive.

---

## 🚀 Features

* **User Authentication:** Secure login and registration screens.
* **Dashboard / Home:** Overview of your active and completed tasks.
* **Task Management:** Create, update, view, and delete tasks seamlessly (using the `Task` model).
* **Confirmation Prompts:** Action confirmations for deleting or completing tasks.

---

## 🛠️ Tech Stack

* **Backend:** PHP, Laravel Framework
* **Frontend:** Blade Templates, Tailwind CSS / HTML
* **Database:** MySQL / SQLite
